ONE-TIME PHONE SETUP

Enable motion.

Phone browsers require a trusted HTTPS connection for gyro steering. This game runs its own local certificate authority on your computer. Installing its public certificate adds that authority to your phone's trust store; only do this for your own trusted game computer. You can remove it after playing. The game never installs certificates automatically.

1. Verify & download

Compare this SHA-256 fingerprint with the game computer's setup page before installing:

Download Room Rally certificate ↓

2. Trust on this phone

iPhone / iPad: Open this setup page in Safari and download the certificate. In Settings, open Profile Downloaded (or General → VPN & Device Management) and install the Room Rally profile. Then enable Room Rally under General → About → Certificate Trust Settings.

Android: In Settings, search “Install a certificate”, choose CA certificate, and select the downloaded file. Labels vary by manufacturer. Chrome uses the device trust store. Remove it from user credentials when you no longer need the game.

3. Connect & calibrate

Open the secure controller below, join the room, tap Enable gyro steering and allow Motion & Orientation. Hold the phone sideways with the screen facing you. Keep it still to center, then turn it like a steering wheel. If you see a certificate warning, return to the trust setup rather than bypassing the warning.

Open secure controller ↗

Without certificate setup, select Touch fallback in the controller to test the race. A phone with working motion sensors is required for gyro steering.
